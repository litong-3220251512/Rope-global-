# PUB-R1.1 CLEVR M10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the preregistered official RoPE-Mixed M10 arm to the accepted CLEVR RGB-plus-question answerer without changing any common non-position component.

**Architecture:** A narrow `CLEVRMixedPosition` module reuses the vendored official initializer, coordinate builder, and complex phase operator. `CLEVRQuestionAnswerer` accepts `mode="M10"`, requires an independent seed, recomputes `[6, 3, 196, 32]` phases every forward, and supplies layer `ell` only to block `ell`; G and B retain their existing path unchanged.

**Tech Stack:** Python 3.11, PyTorch 2.6.0, timm 1.0.24, vendored `naver-ai/rope-vit` commit `48d8df5`, `unittest`.

**Spec:** `docs/clevr_m10_math_and_library_review.md`

## Global Constraints

- PUB-R1.1 in `docs/rope_public_data_experiment_plan.md` is the only current experiment protocol.
- M10 is base 10 with six-layer, three-head, 32-plane learnable two-dimensional frequencies: exactly 1,152 new trainable parameters.
- The public M10 constructor requires a dedicated non-negative integer seed; the formal run builder will later pass `20000 + s`.
- G, B, and M10 must share bitwise-equal non-position initialization under the same common seed.
- Only official RGB and original-question encodings enter the model; no data, weights, pretrained constructor, training, GPU command, or evaluation is authorized here.
- Preserve the existing question-conditioned CLS, manual non-in-place attention, unrotated CLS Q/K, unchanged V, and all frozen backbone dimensions.
- Do not implement Q-only, optimizer grouping, run pairing, resume, metrics, or statistics in this PR.

## Review Focus

- Seed misuse: missing M10 seed or ignored seed on G/B must raise before a misleading run can be constructed; Task 1 tests both boundaries.
- RNG coupling: M10 construction must leave the caller's CPU RNG at the exact state produced by a G construction; Task 1 compares the next random tensor directly.
- Plane mapping: base-10 direction pairs, flattened official storage, and row-major coordinates must map to `[6, 3, 196, 32]`; Task 1 compares official initialization and hand-computed selected phases.
- Numerical gradient path: float64 frequencies and coordinates must support finite-difference checks without dtype mismatch; Task 1 performs gradcheck and invariant checks.
- Stale phase graphs: an update must cause a fresh, changed phase tensor on the next forward; Task 2 observes per-block phases across an update and checks Q/K/frequency gradients.
